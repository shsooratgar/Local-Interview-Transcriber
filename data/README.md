# data/ — your interviews live here (NEVER uploaded)

Everything in this folder **except this README** is git-ignored, so it will
not be committed or pushed to GitHub.

- Put audio files in `data/audio/`
- Put noScribe transcripts in `data/transcripts/`

Give a matching audio and transcript the **same base name** (e.g.
`interview01.m4a` and `interview01.docx`) so the tool can pair them.
